## Flex vs Grid

Jag använder Grid för avgångarna eftersom de ska ligga i rader och kolumner.

Jag använder Flexbox för stoppkorten eftersom de bara ska ligga bredvid varandra.

Jag förstår koden jag pushar och använder AI som hjälp.

Jag valde tre kolumner eftersom avgångarna blir tydliga och får plats bra bredvid varandra.
